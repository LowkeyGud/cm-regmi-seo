## JSX safety rules (violations break `next build`)

1. NEVER put a literal `>` in prose text (e.g. `>50°C`); either reword or use `&gt;`.
2. NEVER put a literal `<` in prose; use `&lt;` or reword.
3. Inside template-literal code blocks (`` `...` ``), escape shell interpolations: write `\${VAR}` not `${VAR}` (else TypeScript resolves them as expressions).
4. Use `&amp;` for `&` in visible text.
5. No bare `{` in text. Attribute values use double quotes.
6. `°C`, `—`, `•` are fine as literal unicode.
